# Security

This repository is a challenge prototype that uses synthetic data only.

Do not submit secrets, tokens, credentials, service-account key files, customer
data, private third-party data, or production enterprise records in issues, pull
requests, or demo inputs.

The prototype demonstrates these controls for the VendorNova workflow:

- derived demo identity instead of request-body privilege upgrades;
- deterministic policy decisions before material retrieval and side effects;
- restricted synthetic chunks filtered before model context;
- approval-gated side effects;
- tamper-evident evidence for demo runs.

These controls are prototype evidence, not production certification, guaranteed
compliance, legal non-repudiation, or universal data-leak prevention.
